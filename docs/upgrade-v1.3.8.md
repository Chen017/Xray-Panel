# v1.3.8 / Script v2.7.13 升级说明

本版本修复 2026-10-27 审查报告的 9 项问题，并迁移到 Zod 4.6.7 以消除报告中的依赖告警。发行本身不会连接或更新任何服务器。

## 生效步骤

1. 建站 VPS 更新 Panel：`xray-panel panel update --version 1.3.8`。管理器会先拉取镜像，再停止旧面板、备份数据库；新版本健康检查期间返回 503 暂停外部请求和任务下发，通过后开放访问，失败则停止候选版本并恢复快照。节点上的 Xray 继续运行。
2. 每台节点 VPS 更新 Agent：`xray-panel agent update --version 1.3.8`。更新保留节点身份、接入凭据和自定义目录。Agent 会使用不低于随包 v2.7.13 的模块，避免旧模块覆盖修复。
3. 每台安装独立 Script 的 VPS 将 Script 更新至 v2.7.13，随后打开一次 `xray` 菜单。启动迁移会在事务中更新已有私网拒绝顺序和内部 XHTTP 入口，先由真实核心校验，失败恢复原配置；活动服务可能短暂重启。只更新脚本文件而不运行迁移，不会改变已加载的核心配置。
4. Panel 管理的节点先「同步当前配置」，再「导入 VPS 当前配置」并预览、部署一次。编译器会修复导入的旧路由和 XHTTP 入口，并保留其他协议入站。已有草稿若仍保留旧配置，也应重新预览后再部署。
5. 若修改了对客户端可见的 UUID、端口、path 或连接参数，刷新订阅；本次内部 tag/socket 迁移本身不改变这些参数。单纯刷新订阅不能替代服务器配置应用。

## 行为与兼容变化

- Node Docker/CI 使用 24.22.1，普通 JSON 和备份恢复接口拒绝压缩请求（415）；Agent 和前端原本就发送未压缩 JSON。更新 npm 依赖不能代替重建 Docker 运行时。
- `geoip:private` 拒绝位于自定义、落地、设备和回退规则之前，包括 loopback 回退后的再次路由。路由使用 `IPOnDemand`，在用户规则前解析并检查域名的目标 IP，避免域名形式绕过私网规则；代价是线路端会增加 DNS 查询，可能改变 DNS 隐私与延迟。故障转移仍保留原有末级公网直出策略。以前通过规则访问私网的配置将被拒绝，本版本没有开放绕过此限制的面板选项；如确需内网链路，应另行设计明确、受限的例外。
- XHTTP tag/socket 根据配置文件名生成；保留原 UUID、path、REALITY 密钥和高级传输字段。重命名配置文件也需要重新生成对应 fallback。
- 租约过期的执行中任务可在节点页或任务历史中「放弃过期任务」。旧回执失效，待同步的授权撤销仍保留；这不保证失联 VPS 上的进程已经停止，恢复操作前应核对当前状态。
- 原生 `xhttpSettings` 缺省/空值、`xmux:null` 以及额外 HTTP 入站可以编译和导出；额外协议不会被写入设备或落地 UUID。
- SNI 监控跟随 Agent 实测配置。目标变化后废弃旧计划及证据，重新累计失败/恢复次数；订阅仍要求成功部署的 applied 配置。
- 诊断新建的临时目录在成功、失败或信号退出时清理；旧版本已经遗留的临时目录不会批量删除，以免误删其他程序文件。

## 验证范围

使用本地临时 SQLite、原生 Linux、真实 Xray 26.3.27 与订阅客户端验证；系统服务、防火墙和 Docker 升级操作使用隔离替身。没有进行生产部署、真实防火墙修改、恶意 Brotli 利用或内存耗尽测试。

自动回归包含认证前压缩请求拒绝、升级停写与最后一次成功撤销保留、任务过期放弃与迟到回执拒绝、混合入站/空 XHTTP 兼容、旧多节点入口迁移、双栈防火墙部分失败恢复、SNI 目标变化以及诊断清理。`npm run test:native` 还运行真实核心的合并配置和认证代理闭环，确认修复后的私网目标无法通过落地回退访问。

本地验证结果：Panel Node 测试 92/92、Agent Python 测试 26/26、生命周期测试 13/13、真实 Agent/Xray/订阅客户端 E2E 18/18 均通过；真实核心另外验证多文件合并、空值配置、IP/域名私网回退阻断。Script Linux 全套隔离回归通过，包含旧缓存失配修复、部分双栈提交失败和诊断 trap 清理。类型检查、Vite 构建、发行包校验与提取后冒烟通过；完整 `npm audit` 为 0 项告警。未将现有 Vite 大 chunk 提示视为构建失败。
