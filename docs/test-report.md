## 1.0.1 审查问题回归

1. 授权同步失败后保留待办，退避后重试并移除旧 UUID；取消任务不丢弃待办。
2. 任务执行期间新增撤销操作，旧任务的成功回执不能确认新授权版本完成。
3. 落地列表 [2,1]、[3,1,2] 与不同故障转移顺序下，各入站的原有中继客户端均匹配正确出口。
4. 自定义 XHTTP Host 保留到 Mihomo provider、VLESS 链接及双栈下载设置。
5. 约 2.56 MB 的加密备份原样恢复成功，记录恢复且旧管理会话失效；普通接口仍拒绝超限正文。
6. 损坏 JSON 时仍发送 Agent 心跳、完成日志任务；面板可显示在线和配置错误，并暂停自动部署。
7. 缓存结果重新读取当前文件；部署目标已经改变或文件无法读取时不发布旧回执。服务端也拒绝重新领取任务前已变更配置的过期成功回执。
8. 多配置文件导出的 VLESS extra 使用各自的路径、上传方法和其他原生 XHTTP 参数。
9. 跨页签的设置、规则、防火墙编辑合并为同一次草稿保存；完整配置与表单冲突时保留编辑并阻止静默覆盖。
